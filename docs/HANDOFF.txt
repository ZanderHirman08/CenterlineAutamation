HOW THE TOOL WORKS
------------------
1. Classifier: numpy logistic regression on per-pixel features (RGB, NIR,
   brightness, saturation, ExG, NDVI + blurred/texture versions; optional
   LiDAR features). Labels from the input road lines: road = within 4 ft,
   not-road = 45-120 ft away. Trained on up to 8 grids, saved as
   road_classifier.json in the work folder (reused if present).
2. Road-probability map per grid (near roads only).
3. Cross-sections every 10 ft, +-40 ft.
4. Refinement method "ribbon" (default): dynamic programming over stations of
   (center offset, width): cover p>0.5 pixels, smooth center, steady width,
   narrowing costs more than widening (shadows), stay_prior pulls toward the
   original line (0.03), cross-sections within 30 ft of junctions ignored
   (find_junctions: shared ends, T's, mid-line crossings). Older "midpoint"
   method still available.
5. Flags (REVIEW=1): low_confidence (CONF<0.2), few_matches (<30% stations),
   large_shift (>15 ft), no_imagery. keep_flagged=True: flagged lines keep the
   ORIGINAL geometry. Output field MOVED (1 = geometry changed).
6. Topology reconnect: least-squares node from end directions, 50 ft taper.
7. Output fields: SRC_ID, GRID_ID, SHIFT_AVG, SHIFT_MAX, CONF, PCT_VALID,
   WIDTH_MED, REVIEW, REASON, MOVED.
Toolbox extras: "LiDAR layers folder" (needs make_lidar_layers.py output;
classifier then adds intensity, canopy height, slope, roughness, canopy x
imagery terms), "Learn from an earlier result" (second pass: retrain from an
earlier output's REVIEW=0 lines using their measured width; use a NEW work
folder). Always use a new work folder per run/setting change.

EVALUATE TOOL ("Evaluate Against Checked Roads")
------------------------------------------------
Reads truth (Roads_working where Validated = 'Yes'), samples every 5 ft,
matches each candidate layer's nearest same-direction line within 40 ft,
reports mean/median/worst10%/<=2ft/<=5ft per cover class (open, shadow,
partial, canopy, intersection; cover from NDVI/brightness around each point).
Only grids selected in the grid layer are used; optional output check points
with ERR_1..ERR_n (order = order of layers listed). Read-only on inputs.
